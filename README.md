# Student-Monitoring-System

A **MERN Stack–based Student Monitoring System** designed to manage students, attendance, and basic academic monitoring in an efficient and user-friendly way. This project is suitable for mini-projects, academic submissions, and learning full‑stack development.

---

## 🚀 Features

### 👩‍🏫 Admin / Teacher

* Add, update, and delete students
* Mark student attendance (Present / Absent)
* View attendance reports
* Monitor student performance

### 👨‍🎓 Student

* Login securely
* View attendance percentage
* Check eligibility based on attendance (e.g., 75% rule)

---

## 🛠️ Tech Stack

### Frontend

* **React.js** (Vite)
* **React Router DOM**
* **Axios**
* **Tailwind CSS**
* **Recharts** (for charts & analytics)

### Backend

* **Node.js**
* **Express.js**
* **MongoDB**
* **Mongoose**

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Student-Monitoring-System.git
cd Student-Monitoring-System
```

---

### 2️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on: **[http://localhost:5173](http://localhost:5173)**

---

### 3️⃣ Backend Setup

```bash
cd backend
npm install
npm start
```

Backend runs on: **[http://localhost:5001](http://localhost:5001)**

Make sure MongoDB is running locally or use MongoDB Atlas.

---

## 🌐 Deployment

### Frontend (Vercel)

* Framework: **Vite**
* Root Directory: `frontend`
* Build Command: `npm run build`
* Output Directory: `dist`

### Backend (Render / Railway)

* Build Command: `npm install`
* Start Command: `npm start`
